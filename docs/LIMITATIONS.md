# Limitations and safe use

- This is a student educational prototype, not a certified or validated medical device.
- Current browser results are randomized illustrative examples, not model predictions.
- A chest X-ray classifier can fail on out-of-distribution images, different acquisition settings, demographic groups, or label errors.
- Dataset-level metrics do not establish clinical safety or utility.
- Never use this project to diagnose, triage, or treat a person.
- Do not upload identifiable patient images or commit private medical data to GitHub.
